# 术语

【术语】是独立的只读搜索页。唯一数据源是前端源码
`frontend/src/glossary/entries.ts`，构建后随管理台发布；它不存 SQLite，也不进入配置仓库。

每项包含正式英文名、文本变体、中文名、中英解释、分类与来源。变体只表示同一术语的大小写、
分隔形式、类名或公认缩写；含义不同的近义概念必须分开成条。

页面使用单表头四列列表展示“术语”“变体”“分类”“中英文说明与来源”，字段名不会在每条记录中重复。
列表区域独立纵向滚动，表头保持可见；长英文、稳定 key、说明与来源链接在各自单元格内换行，不产生
横向滚动条。列表可按两类 scope 多选筛选，并支持首页、上一页、下一页、末页、直接页码跳转和每页
25/50/100 条；它是只读数据源，不显示创建、编辑、删除或批量动作。

当前源码包含 458 个 `ai-agent-concept` 与 257 个 `project-technology` 条目，并按正式英文名
ASCII 排序。搜索对英文、变体、中文名和双语解释执行 NFKC 归一化、忽略大小写的包含匹配；筛选草稿
只有提交后才改变结果，重置会恢复全部条目。业务代码只在明确需要产品中文名称时
按稳定 key 查询，不全局翻译 SDK 类名、payload key 或用户数据。
