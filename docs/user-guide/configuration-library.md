# 管理配置仓库

【配置仓库】按组件、Main Agent 和 Subagent 分类显示已保存记录，支持搜索、查看详情、编辑、复制、
单项删除和批量删除。

- 编辑会跳转到对应页面，并以记录 UUID 确定更新目标；
- 复制会创建新 UUID，副本名称经过当前校验；
- 详情显示保存的完整 payload，包括当前版本无法识别或无法运行的记录；
- 删除可选组件或 Subagent 实体时，服务端会在一次配置更新中从所有 Agent 配置摘除对应引用；
- Main Agent 必选的模型和 Agent 事件输出在仍被引用时删除会返回冲突，替代配置解除引用后即可删除；
- Main Agent 被任一 Workflow Graph 的 Agent Node 引用时，单项或批量删除都会返回冲突；批量删除不会先删除其中未引用的记录；
- 批量删除与引用摘除由文件配置仓库统一写入；每条记录保存为独立 YAML 文件；
- 当前版本不再支持的组件类型会显示为失效引用，可在 Agent 编辑页移除，删除该历史组件时也会自动摘除引用。

无效记录可以查看和编辑，但复制与运行仍会重新校验。配置唯一保存在 `data/config/` 的 YAML 和
`system.yaml` 中；SQLite 只保存运行记录。
