# 管理配置仓库

【配置仓库】按组件、Primary Agent 和 Subagent 分类显示已保存记录，支持搜索、查看详情、编辑、复制、
单项删除和批量删除。

- 编辑会跳转到对应页面，并以记录 UUID 确定更新目标；
- 复制会创建新 UUID，副本名称必须符合当前校验；
- 详情显示保存的完整 payload，包括当前版本无法识别或无法运行的记录；
- 删除可选组件、Subagent 实体或自动化工作流时，服务端会在同一事务中从所有 Agent 配置摘除对应引用；
- Primary 必选的模型和输出模式不能在仍被引用时删除，应先为相关 Primary 选择替代配置；
- 批量删除与引用摘除是同一个原子操作，任一步失败时整批回滚；
- 当前版本不再支持的组件类型会显示为失效引用，可在 Agent 编辑页移除，删除该历史组件时也会自动摘除引用。

无效记录可以查看和编辑，但复制与运行仍会重新校验。需要保留的数据应通过页面修正后保存，不要直接
修改 SQLite。
